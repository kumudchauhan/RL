This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

This is an information extraction project focused on parsing structured data from invoices and order confirmations. The project is in early stages — currently it contains only sample input documents with no extraction code yet.

## Data

The `invoices/` directory contains sample documents for extraction:
- **PDF invoices**: Amazon orders, restaurant invoices, general invoices
- **Email order confirmations** (`.eml` files): Orders from retailers (Acme, Acme Cosmetics, Store, etc.)

These documents represent the input formats the extraction system needs to handle.
